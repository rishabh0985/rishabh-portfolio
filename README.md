# Rishabh Kushwah — Graphic Designer Portfolio

A dark 3D, story-style portfolio website: glass cards, glowing borders, a 3D project ring and a full project viewer.

- **Live site:** https://rishabh0985.github.io/rishabh-portfolio/
- **Behance:** https://www.behance.net/rishabhkushwah5
- **Instagram:** https://www.instagram.com/death_design01/

## Files
- `index.html` — the whole site (HTML, CSS and JS)
- `data.js` — list of projects (titles, categories, images). Edit this to add or change work.
- `work/` — creatives from Behance (`.webp` full size, `.thumb.jpg` previews)
- `assets/` — profile photo and the downloadable resume PDF

## Add a new project
1. Make a folder in `work/` (e.g. `work/my-project/`) and put the images in it.
2. Add an entry to `data.js` with the title, category, Behance link and image paths.
